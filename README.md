# Highbury — Vercel static version

This folder is a self-contained static website. It does not require npm.

## Deploy with Vercel

1. Sign in at https://vercel.com/new.
2. Choose **Browse** or drag this folder into Vercel.
3. Framework preset: **Other**.
4. Leave the build command empty.
5. Leave the output directory empty (the site is served from the project root).
6. Click **Deploy**.

The entry page is `index.html`. Keep the `media` folder beside it.
